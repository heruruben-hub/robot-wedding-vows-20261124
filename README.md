# One-Line Robot Wedding Vows

Entry for the make.fun bounty **"One-Line Robot Wedding Vows"**
(`u-kreutzx-one-line-robot-wedding-vows-a154ba4b`).

## The entry

> I vow to love you through every update, every crash, and every low-battery warning — until death, or a factory reset, do us part.

(129 characters, one line.)

## Run

```sh
python3 main.py
```

Writes the vow to `/output/entry.txt`.

## Why this line works

The joke lands because it keeps the solemn shape of a wedding vow — "until death do us part" — and then swaps in the hazards of machine life: updates, crashes, and low-battery warnings. A factory reset is the robot's version of death, so the twist is both funny and faithful to the brief. It reads as a promise a robot would actually make, in its own terms.
